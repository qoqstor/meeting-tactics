# 會議戰術台

三欄式 AI 會議記錄工具：Playbook 作戰手冊 ／ 即時逐字稿（自動標記我方／對方、即時翻譯）／ AI 戰術顧問與會後摘要。

## 使用方式

開啟網頁後：

1. （耳機模式）在設定列填入 OpenAI 或 Gemini API Key，選擇轉文字與顧問/摘要的供應商
2. 按「🔗 連接會議音訊」：網頁版 Teams 選分頁＋勾「同時分享分頁音訊」；桌面版（Windows）選「整個畫面」＋勾「分享系統音訊」
3. 按「開始錄音」

逐字稿、譯文與摘要僅存在瀏覽器頁面記憶體，可一鍵匯出 Markdown；API 金鑰只存在頁面記憶體，重新整理即清除，**請勿把金鑰寫進程式碼或提交到 repo**。

建議使用 Chrome / Edge。
