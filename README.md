# 會議戰術台

三欄式 AI 會議記錄工具，靈感來自 [AI 會議筆記工作流](https://yu-wenhao.com/zh-TW/blog/ai-meeting-notes/)：**Playbook 作戰手冊**／**即時逐字稿**（自動標記我方／對方、即時翻譯）／**AI 戰術顧問**與會後正式會議紀錄。純前端單頁應用，所有資料只存在瀏覽器頁面記憶體，不經過任何後端伺服器。

## 功能總覽

- **即時逐字稿**：依說話節奏切段（停頓 0.8 秒即送、最長 8 秒），講完一句約 1–3 秒上稿；每句可點擊修改、滑過按 ✕ 刪除誤偵測句
- **我方／對方自動標記**：會議音訊（擷取）判為對方、麥克風判為我方，標記錯誤可點標籤切換
- **即時翻譯**：外語段落（日/韓/英）自動翻成繁體中文，顯示於原文下方「譯」標籤，譯文也可點擊修改
- **中/日混合模式**：同段混語各自照原語言轉錄，適合雙語會議
- **AI 戰術顧問**：會議中一鍵根據 Playbook 與最近對話給出接話建議
- **會議紀錄**：一鍵產出正式紀錄（摘要含 Playbook 目標對照、討論重點、決策、行動項目表、未決事項），可匯出 Markdown
- **防誤聽**：我方收音靈敏度可調、須持續出聲才上傳、幻覺短句自動過濾
- **限流自動備援**：Gemini 模型觸發額度上限時自動切換替代模型，冷卻後切回主模型

## 快速開始（標準流程）

1. 用 **Chrome / Edge** 開啟頁面，在設定列填入 **Gemini API Key**（[AI Studio](https://aistudio.google.com) 免費申請；預設供應商與模型已設為 Gemini 3.1 Flash Lite）
2. 按 **「📝 記錄模式」**：一鍵開啟雙聲道 API 轉文字（我方＋對方）
3. 按 **「🔗 連接會議音訊」**：
   - 網頁版 Teams／Meet：選該**分頁**，勾選「同時分享分頁音訊」
   - Teams 桌面版（Windows）：選「**整個畫面**」，勾選「分享系統音訊」（選「視窗」抓不到聲音）
4. 按 **「開始錄音」**（首次允許麥克風請選「造訪這個網站時允許」）
5. 視需要開啟 **「🈂 即時翻譯」**、隨時按 **「⚡ 給我建議」**
6. 會後：校對逐字稿 →「產生會議摘要」→「匯出 Markdown」

## 模式說明

| 模式 | 條件 | 我方 | 對方 |
|---|---|---|---|
| 喇叭模式（免金鑰） | 用喇叭開會、不戴耳機 | 瀏覽器辨識 | 瀏覽器辨識（經麥克風收音，準確度有限） |
| 耳機模式 | 需轉文字 API Key | 瀏覽器辨識 | 會議音訊送 API |
| 📝 記錄模式（建議） | 需轉文字 API Key | 麥克風送 API | 會議音訊送 API |

## API 供應商

| 用途 | 選項 | 備註 |
|---|---|---|
| 轉文字 | Gemini（預設）／OpenAI | Gemini 自動偵測語言；OpenAI 用 gpt-4o-mini-transcribe，約 $0.18/hr/聲道 |
| 翻譯・顧問・摘要 | Gemini（預設）／Claude | Claude 需填 Anthropic Key |

Gemini 免費額度參考：3.1 Flash Lite 為 15 RPM／500 RPD，足夠一般會議；密集雙語長會建議綁定計費或轉文字改用 OpenAI 分流。

## 隱私與安全

- 逐字稿、譯文、摘要僅存於頁面記憶體，重新整理即清除；請會後即時「匯出 Markdown」保存
- API 金鑰只在頁面執行時輸入與保存於記憶體，**切勿寫進程式碼或提交至 repo**
- 音訊段落會送至所選供應商（Google／OpenAI／Anthropic）轉文字與生成，機密會議請依公司規範評估

## 已知限制

- 需 Chrome / Edge；逐字顯示為「一句一句出」，非字幕式逐字浮現（REST 切段架構限制）
- 戴耳機時對方逐字稿必須走 API（瀏覽器辨識物理上聽不到耳機內的聲音）
- 講者分離為音源判定（會議音訊 vs 麥克風），無法再細分對方多位與會者
