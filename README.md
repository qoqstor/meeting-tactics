# 會議戰術台

三欄式 AI 會議工具，靈感來自 [AI 會議筆記工作流](https://yu-wenhao.com/zh-TW/blog/ai-meeting-notes/)：**Playbook 作戰手冊**／**即時逐字稿與翻譯**／**AI 戰術顧問**與會後正式會議紀錄，並支援**直播共享**（字幕、聊天室、同傳語音）。純前端單頁應用，無後端伺服器，所有資料只存在瀏覽器頁面記憶體。

## 功能總覽

### 逐字稿與翻譯
- **即時逐字稿**：依說話節奏切段（停頓 0.8 秒即送、最長 8 秒），講完一句約 1–3 秒上稿
- **我方／對方自動標記**：會議音訊（擷取）→ 對方、麥克風 → 我方；點標籤可手動切換
- **逐句校正**：點文字直接修改（Enter 儲存／Esc 取消）、滑過按 ✕ 刪除誤偵測句，譯文同樣可改
- **🈂 即時翻譯**：外語段落自動翻成繁體中文，原文先上稿、下方顯示「…翻譯中」再原地補上譯文
- **🛰 Live 同傳**（Gemini 3.5 Live Translate）：對方外語即時轉為**中文語音**（耳機播放）＋串流字幕，停頓後自動落稿為正式段落；對方講中文時自動略過
- **中/日混合模式**：同段混語各自照原語言轉錄，適合雙語會議
- **防誤聽**：我方收音靈敏度可調、須持續出聲 0.5 秒才上傳、自動過濾雜訊幻覺短句

### AI 輔助
- **⚡ 戰術顧問**：會議中一鍵根據 Playbook 與最近對話給出可直接說出口的接話建議
- **會議紀錄**：一鍵產出正式紀錄（摘要含 Playbook 目標對照、討論重點、決策、行動項目表、未決事項），可匯出 Markdown
- **限流自動備援**：Gemini 模型觸發額度上限時自動切換替代模型並冷卻計時，冷卻後切回主模型

### 📡 直播共享（觀看端零 API 消耗）
- 主持端產生 6 碼驗證碼，其他人輸入即同步觀看逐字稿與譯文；中途加入自動補齊完整內容
- **💬 聊天室**：所有成員可傳文字與表情符號，訊息附發送時間
- **🔈 同傳語音直播**：Live 同傳的中文語音可同步播給觀看端（適合 1–5 人）
- 主持端開始／停止錄音、結束直播，觀看端都會即時收到通知
- 所有直播內容以驗證碼衍生的 **AES-256 金鑰端對端加密**後經公共 MQTT 通道傳輸

## 快速開始（標準流程）

1. 用 **Chrome / Edge** 開啟頁面，填入 **Gemini API Key**（[AI Studio](https://aistudio.google.com) 免費申請；預設供應商與模型已設為 Gemini 3.1 Flash Lite）
2. 按 **「📝 記錄模式」**：一鍵開啟雙聲道 API 轉文字（我方＋對方）
3. 按 **「🔗 連接會議音訊」**：
   - 網頁版 Teams／Meet：選該**分頁**，勾選「同時分享分頁音訊」
   - Teams 桌面版（Windows）：選「**整個畫面**」，勾選「分享系統音訊」（選「視窗」抓不到聲音）
4. 按 **「開始錄音」**（首次允許麥克風請選「造訪這個網站時允許」）
5. 視需要開啟「🈂 即時翻譯」或「🛰 Live 同傳」、需要共享時開「📡 分享直播」
6. 會後：校對逐字稿 →「產生會議摘要」→「匯出 Markdown」

## 模式說明

| 模式 | 條件 | 我方 | 對方 |
|---|---|---|---|
| 喇叭模式（免金鑰） | 用喇叭開會、不戴耳機 | 瀏覽器辨識 | 瀏覽器辨識（經麥克風，準確度有限） |
| 耳機模式 | 需轉文字 API Key | 瀏覽器辨識 | 會議音訊送 API |
| 📝 記錄模式（建議） | 需轉文字 API Key | 麥克風送 API | 會議音訊送 API |

翻譯方式二選一（可並存切換）：**🈂 即時翻譯**＝文字字幕，省額度；**🛰 Live 同傳**＝中文語音＋字幕，體驗最好但為 preview 模型、串流用量較大。

## API 供應商

| 用途 | 選項 | 備註 |
|---|---|---|
| 轉文字 | Gemini（預設）／OpenAI | Gemini 自動偵測語言；OpenAI 用 gpt-4o-mini-transcribe，約 $0.18/hr/聲道 |
| 翻譯・顧問・摘要 | Gemini（預設）／Claude | Claude 需填 Anthropic Key |
| Live 同傳 | gemini-3.5-live-translate-preview | 需 Gemini Key，public preview |

Gemini 免費額度參考：3.1 Flash Lite 為 15 RPM／500 RPD，足夠一般會議；密集雙語長會建議綁定計費或轉文字改用 OpenAI 分流。

## 手機使用

手機瀏覽器不支援畫面音訊擷取，無法用於線上會議的對方聲道；適合**實體會議**：Android Chrome 開啟頁面 → 耳機模式＋勾「我方也用 API 轉」→ 開始錄音（手機放桌上收音，螢幕需保持亮著）。觀看直播、聊天室在手機上正常可用。

## 隱私與安全

- 逐字稿、譯文、摘要、聊天紀錄僅存於頁面記憶體，重新整理即清除；請會後即時「匯出 Markdown」
- API 金鑰只在執行時輸入並存於記憶體，**切勿寫進程式碼或提交至 repo**
- 音訊會送至所選供應商（Google／OpenAI／Anthropic）處理；直播內容雖經端對端加密，但流量經第三方公共 MQTT 節點——機密程度極高的會議請勿開直播

## 已知限制

- 需 Chrome / Edge；切塊模式為「一句一句出」，逐字浮現體驗請用 Live 同傳
- 戴耳機時對方逐字稿必須走 API（瀏覽器辨識物理上聽不到耳機內的聲音）
- 講者分離為音源判定（會議音訊 vs 麥克風），無法細分對方多位與會者
- Live 同傳為 preview 模型：快速多人交談或重口音時輸入逐字稿可能標錯語言（譯文仍準確），額度政策可能變動
- 同傳語音直播走免費公共節點，人數多或網路差時可能斷續（字幕不受影響）
