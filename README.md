# 會議戰術台

三欄式 AI 會議工具，靈感來自 [AI 會議筆記工作流](https://yu-wenhao.com/zh-TW/blog/ai-meeting-notes/)。支援即時逐字稿與翻譯、AI 戰術顧問、正式會議紀錄、直播共享，以及手機主持與觀看。純前端單頁應用，無後端伺服器，所有資料只存在瀏覽器頁面記憶體。

---

## 最新更新（此版）

### 手機支援全面升級
- **📱 手機收音模式**：手機開啟頁面時自動出現，一鍵啟用麥克風 API 轉文字與即時翻譯，不再因缺少會議音訊而卡住
- **📺 影片音源模式**：停用軟體層回音消除（echoCancellation: false），讓手機麥克風能收到喇叭播出的影片聲音並翻譯
- **⚙ 金鑰設定面板**：手機專用底部滑出面板，可填 Gemini Key、選模型、切換影片音源模式，不再需要操作擁擠的桌面設定列
- **iOS Safari 相容修正**：自動偵測瀏覽器支援的音訊格式（webm → ogg → mp4），iOS 的 MediaRecorder 現在使用 mp4，轉文字與翻譯可正常運作
- **手機隱藏不支援功能**：手機開啟時自動隱藏「🔗 連接會議音訊」「🛰 Live 同傳」「🔈 同傳語音直播」等手機無法使用的按鈕，介面更簡潔

## 功能總覽

### 逐字稿與翻譯
- **即時逐字稿**：依說話節奏切段（停頓 0.8 秒即送、最長 8 秒），講完一句約 1–3 秒上稿
- **我方／對方自動標記**：會議音訊（擷取）→ 對方、麥克風 → 我方；點標籤可手動切換
- **逐句校正**：點文字直接修改（Enter 儲存／Esc 取消）、滑過按 ✕ 刪除誤偵測句，譯文同樣可修改
- **🈂 即時翻譯**：外語段落（日／韓／英）自動翻成繁體中文，原文先上稿、下方「…翻譯中」再原地補譯文
- **🛰 Live 同傳**（Gemini 3.5 Live Translate）：對方外語即時轉為中文語音（耳機播放）＋串流字幕，停頓後自動落稿；對方講中文自動略過
- **中/日混合模式**：同段混語各自照原語言轉錄，適合雙語會議
- **防誤聽**：我方收音靈敏度可調、持續出聲 0.5 秒才上傳、自動過濾雜訊幻覺短句

### AI 輔助
- **⚡ 戰術顧問**：會議中一鍵根據 Playbook 與最近對話給出可直接說出口的接話建議
- **📝 記錄模式**：一鍵開啟雙聲道 API 轉文字（我方＋對方），手機上自動只啟用我方
- **會議紀錄**：一鍵產出正式紀錄（摘要含 Playbook 目標對照、討論重點、決策、行動項目表、未決事項），可匯出 Markdown
- **Gemini 限流自動備援**：觸發額度上限時自動切換替代模型並冷卻計時，冷卻後切回主模型

### 📡 直播共享（觀看端零 API 消耗）
- 主持端產生 6 碼驗證碼，其他人輸入後即同步觀看逐字稿與譯文；中途加入自動補齊完整內容
- **💬 聊天室**：所有成員可傳文字與表情符號，訊息附發送時間（HH:MM）
- **🔈 同傳語音直播**：Live 同傳的中文語音同步播給觀看端（適合 1–5 人）
- 主持端開始錄音、停止錄音、結束直播，觀看端即時收到通知
- 所有直播內容以驗證碼衍生的 **AES-256 金鑰端對端加密**後經公共 MQTT 通道傳輸

## 快速開始

### 電腦（Teams / Meet 線上會議）
1. 用 **Chrome / Edge** 開啟 `https://qoqstor.github.io/meeting-tactics/`，在設定列填入 **Gemini Key**（[AI Studio](https://aistudio.google.com) 免費申請）
2. 按「**📝 記錄模式**」（自動開啟雙聲道 API 轉文字）
3. 按「**🔗 連接會議音訊**」：
   - 網頁版 Teams／Meet：選該**分頁**＋勾「同時分享分頁音訊」
   - Teams 桌面版（Windows）：選「**整個畫面**」＋勾「分享系統音訊」
4. 按「**開始錄音**」（首次請選「造訪這個網站時允許」）
5. 視需要開「🈂 即時翻譯」或「🛰 Live 同傳」、需要共享時開「📡 分享直播」
6. 會後：校對逐字稿 → 產生會議摘要 → 匯出 Markdown

### 手機（實體會議 / 影片翻譯）
1. 用 **Android Chrome** 開啟頁面，點頁尾「**⚙ 金鑰設定**」填入 Gemini Key
2. 翻譯影片音源：勾選「**📺 影片音源模式**」→ 儲存，把影片音量調大（建議 70%+）
3. 按「**📱 手機收音：開**」→「**🈂 即時翻譯：開**」→「**開始錄音**」
4. 手機也可**加入直播**觀看電腦主持端的逐字稿、譯文，並參與聊天室

## 模式對照

| 模式 | 適用場景 | 我方 | 對方 |
|---|---|---|---|
| 喇叭模式（免金鑰）| 用喇叭開會 | 瀏覽器辨識 | 瀏覽器辨識（準確度有限）|
| 🎧 耳機模式 | 戴耳機開會 | 瀏覽器辨識 | 會議音訊送 API |
| 📝 記錄模式（建議）| 戴耳機，追求品質 | 麥克風送 API | 會議音訊送 API |
| 📱 手機收音 | 手機實體會議 | 麥克風送 API | ✗（手機不支援擷取）|

翻譯方式：**🈂 即時翻譯**（文字字幕，省額度）vs **🛰 Live 同傳**（中文語音＋字幕，需 preview 模型授權）

## 隱私與安全

- 逐字稿、譯文、摘要、聊天紀錄**僅存於頁面記憶體**，重新整理即清除；請會後即時匯出 Markdown
- API 金鑰只在執行時輸入並存於記憶體，**切勿寫進程式碼或提交至 repo**
- 音訊會送至所選供應商（Google／OpenAI／Anthropic）處理
- 直播內容雖經端對端加密，但流量經第三方公共 MQTT 節點，機密會議請勿開直播

## 已知限制

- 需 Chrome / Edge（iOS Safari 僅 API 模式可用，瀏覽器辨識不支援）
- 戴耳機時對方逐字稿必須走 API（麥克風物理上聽不到耳機內的聲音）
- 講者分離為音源判定（會議音訊 vs 麥克風），無法細分對方多位與會者
- 手機無法擷取線上會議對方聲音（瀏覽器封鎖 getDisplayMedia）
- 手機影片音源模式需要影片音量夠大；部分 Android 旗艦機有硬體層回音消除，軟體無法停用
- Live 同傳為 preview 模型，額度政策可能變動；同傳語音直播走免費公共節點，多人時可能斷續
